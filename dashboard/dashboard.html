💡 如何获取 Google 表格接收链接 (Apps Script Webhook)？（点击展开/折叠简易教程） ▼
  1. 新建或打开你的任意 Google 表格，点击顶部菜单的 扩展程序 (Extensions) ➔ Apps Script。
  2. 将下方代码框中的脚本全选覆盖粘贴到编辑器中，点击顶部的 💾 保存图标。
  3. 点击右上角的 部署 (Deploy) ➔ 新建部署 (New deployment)。
  4. 点击齿轮图标选择 Web 应用 (Web app)，配置：
    • 说明：可留空或输入 FB线索接收
    • 执行身份 (Execute as)：我 (Me)
    • 谁可以访问 (Who has access)：选择 任何人 (Anyone)（⚠️ 关键！否则插件无法免密提交数据）
  5. 点击 部署 (Deploy)，在弹窗中授予权限，复制生成的 Web 应用网址 (Web App URL)，填入下方表格配置即可！
Google Apps Script 接收端通用脚本 
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheetName = data.sheetName || "Sheet1";
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(sheetName) || ss.getSheets()[0];
    
    // 如果表格为空，自动初始化 14 列标准表头
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "FB id", "姓名", "自定义字段", "来源", "标签", 
        "订阅时间", "性别", "最新贴文", "评论贴文", 
        "评论内容", "日期", "时间点", "专页id", "创建时间"
      ]);
    }
    
    // 写入当前线索数据行
    sheet.appendRow(data.row);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success", message: "数据已写入" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
